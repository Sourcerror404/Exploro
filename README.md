# Exploro 🌿
### Find the Unseen. Live the Unwritten.

Exploro is a community-powered exploration platform designed to help people discover local places, share photos, and engage with their surroundings. It aims to make exploration more rewarding through an experience-point (EXP) system and redemption features.

Our vision is to connect explorers, local communities, and independent businesses while helping lesser-known destinations gain visibility.

## 🎯 The Problem

Popular destinations and familiar routes often dominate people's attention, leaving lesser-known local places and independent businesses overlooked.

Exploro aims to make local discovery more engaging by combining a place-discovery experience with photo sharing and an EXP-based reward system.

## 💡 Our Solution

Exploro provides a foundation for community-powered exploration. Users can interact with a map-style interface, upload pictures, accumulate or use EXP through the available redemption experience, and discover how exploration could become more rewarding.

The long-term vision is to help users discover overlooked places and support local communities through meaningful experiences.

## ✨ Current Features

### 🗺️ Map-Style Interface
- Browse a map-inspired discovery interface.
- Explore the foundation for future location-based features.
- Live mapping and verified place data are not yet integrated.

### 📸 Photo Uploads
- Upload pictures through the interface.
- Support the concept of sharing discoveries.
- Uploaded photos are not currently verified against GPS coordinates.

### ⭐ EXP and Redemption
- Interact with the EXP-based reward redemption feature.
- Explore the platform's reward-oriented experience.
- Actual redemption behavior, reward availability, and persistence depend on the current prototype implementation.

## 🛠️ Technology Stack

The initial frontend prototype uses:

- **HTML5** — Structure and content.
- **CSS3** — Styling and responsive layout.
- **JavaScript** — Frontend interactions and interface logic.

Potential future integrations include:

- **Leaflet and OpenStreetMap** for live maps.
- **Browser Geolocation API** for optional device location access.
- **Supabase** for authentication, persistent data, and image storage.

These integrations are planned and are not yet part of the current prototype.

## 🚧 Current Limitations

- The map interface is not connected to a live mapping API.
- GPS access and location verification are not implemented.
- Photo uploads do not establish that a user visited a particular location.
- Quest-based exploration is not currently implemented.
- Persistent storage and backend functionality may be limited or unavailable.
- EXP redemption should not be assumed to represent real monetary value or guaranteed partner rewards.
